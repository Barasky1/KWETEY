# AI Video Studio

A separate workspace for the AI video creation and publishing platform.

The initial app will target 30-second vertical videos and later add AI scripts, generated images, narration, video rendering, scheduling, and authorized publishing to YouTube, TikTok, and Facebook.

This project is isolated in its own folder and branch. Existing KWETEY application files are not being replaced.

## Build

- Install dependencies with `npm install`.
- Build the frontend with `npm run build`.
- TypeScript configuration is in `tsconfig.json`.

## Status

- Project folder created.
- Frontend starter dashboard is in place.
- AI generation, rendering, scheduling, and social publishing integrations are not connected yet; platform authorization and API credentials will be required.


Deployment trigger check: Cloudflare Pages path filtering is disabled for this project so commits on this production branch are not skipped.
